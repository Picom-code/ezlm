From download to your own AI in four steps

The same four steps every time, and EZLM does the work in each one.

  1. 1

    Scan

    Checks your processor, memory, graphics card and disk, and what's already using them.

  2. 2

    Choose

    Picks the smartest model that runs well here. Pick Balanced, Smartest or Fastest if you want a say.

  3. 3

    Install

    Downloads the AI engine and the model. Cancel any time; it picks up where it stopped.

  4. 4

    Ready

    You get an address and a key that work in any app that supports the OpenAI API.

What your PC needs

EZLM sizes the model to your computer, so most PCs from the last few years can run something good.

Windows
Windows 10 (version 2004 or later) or Windows 11Regular (x64) and ARM PCs, including Snapdragon and NVIDIA RTX Spark laptops
Graphics
An NVIDIA graphics card makes it fastestAMD and Intel graphics run through Vulkan; no graphics card works too, just slower
Memory
16 GB or more is a good startMore memory means smarter models: a 12 GB graphics card with 62 GB of memory runs a 180B-parameter model at about 20 words a second
Disk space
1 to 70 GB, depending on the modelEZLM tells you before a download needs more room than you have

Installing the beta

This beta isn't code-signed yet, so Windows asks you to confirm the first time.

  1. Open EZLM-Setup.exe from your downloads. Already have EZLM 0.1.0? Run it anyway: it updates EZLM and keeps your models.
  2. If Windows shows Windows protected your PC, click More info, then Run anyway.
  3. Click through the installer. It opens EZLM at the end and starts the scan.
  4. Something not right? In EZLM, press Report a problem (bottom left), say what happened, and send it. Reports are public on GitHub; your keys and files are never included.
