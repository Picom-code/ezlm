# First run

The first time you open EZLM it looks at your computer, compares what it finds with the models it knows, and offers you the one it thinks suits you best. You choose whether to set that up or pick another. Nothing you type later is sent anywhere, and the first check sends nothing about your computer.

## The five checks you will see

EZLM shows a short starting screen, then a list of five checks, each with a tick when it is done. The same five lines appear on Windows and on a Mac.

- **Processor**: the name of your processor and how many threads it has.
- **System memory**: how much memory is free right now, and how much is installed. Free is the number that matters, because other apps are already using the rest.
- **Graphics**: your graphics card and how much of its memory is free, for example "NVIDIA GeForce RTX 3060, 10.4 GB free of 12 GB". On an Apple Silicon Mac it says "Shares system memory, up to X GB for AI", because the chip uses the same memory for everything. On a computer with no supported card it says "No graphics card found, the processor will run it".
- **Disk space**: free space in the folder where models will be saved.
- **Comparing models against your memory**: how many ways EZLM found to run a model here. "Nothing fits right now" means no model fits in the memory that is free.

The numbers are a snapshot taken at that moment. Free memory and free disk space change as you use the computer, so the same screen can show different numbers an hour later.

## The screen after the scan

The next screen has two parts.

On the left is the model EZLM suggests. It shows the name, the file it will download, the download size, the speed in words per second, the context size, and whether the model works with coding agents. It also shows two bars: how much memory the model needs and how much is left over. On Windows it also shows where the model will be saved, with a **Change** button.

On the right is a switch with **Balanced**, **Smartest** and **Fastest**, and a list of up to 14 other ways to run a model on this computer. The suggested one is tagged **Recommended** and is already selected. If another program is using your graphics card, EZLM lists it here.

At the bottom of the left side are three buttons: **Set it up**, **Scan again** and **Free up memory**.

## The model it picks

The first model is the one tagged **Recommended**, at the top of the list and already selected, so **Set it up** works straight away.

To choose it, EZLM tries every model in its list with every file size, context size and memory placement that fits, then ranks the results by how smart the model is, adjusted for the quality lost in compression, as long as the speed is usable. **Balanced** is the default. **Smartest** ignores speed and **Fastest** weighs speed heavily. Changing the switch runs the comparison again and moves the selection to the new recommendation.

EZLM always leaves room for the operating system and your open apps before it plans a model. That is why the pick on a busy computer can be smaller than the same computer could run after you close a few apps. The model's download size is not limited by free disk space: if the download needs more room than you have, the screen says so in gold and lets you set it up anyway while you make room.

## How long it takes

Usually a few seconds. The checklist alone takes about two seconds on purpose, so you have time to read it, even when the check itself is instant. Three things can make it slower:

- The first start of EZLM's engine can take a few seconds, and up to 30 seconds before it reports a problem. Antivirus software scanning a new program is the usual cause.
- EZLM checks the internet for an updated model list and waits at most four seconds for it. With no connection it uses the list built into the app, so the result is the same, just from an older list.
- A slow or very full disk can slow the check of free space.

If EZLM shows "Something went wrong" with a message, press **Try again**. If it happens twice, press **Report this problem**.

## If the detection looks wrong

1. Close the apps you are not using, wait about 20 seconds, then press **Scan again**. EZLM reuses a hardware check for 20 seconds, so rescanning immediately after closing apps can show the old numbers.
2. Press **Free up memory** instead if you want EZLM to walk you through closing apps one at a time. It asks before closing anything.
3. Open **System** in the list on the left. It shows the processor, graphics, the engine EZLM chose (NVIDIA CUDA, Apple Metal, Vulkan or Processor only) and the storage folder. If the graphics line says "None found" but you have a card, update its driver, quit EZLM and open it again.
4. If the storage folder is on a small drive, change it on the first screen with **Change** next to **Saves to** (Windows), or in **Settings** (Mac). On Windows the first setup may already have put models on the drive with the most free space.
5. If memory looks lower than you expect, remember that free memory excludes what your open apps already use. Close them and scan again.
6. If the numbers are still wrong, press **Report a problem** at the bottom left, or **Copy details for support** on an error. The report includes the hardware summary and recent logs, not your keys, your files or anything you typed to a model.
