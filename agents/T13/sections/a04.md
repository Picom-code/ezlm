## Picking or switching a model

EZLM starts with one recommended model, and you can change it at any time from **Models**. The URL, the keys and the apps you connected stay the same when you switch.[^1]

### The model list

Open **Models** to see two lists.

**On this computer** lists the models you already downloaded. Each row shows the file size, its speed and context on this machine, or "doesn't fit in free memory right now" when it needs more memory than is free.[^2] Press **Switch** to use one, or **Remove** to delete it and free the space.[^3] The model that is running has a **Running** badge and cannot be removed until you switch to another one.[^4]

**Get another model** lists the models that fit this computer, best first. The app shows up to 14 options, so on a large machine some models that fit may not be listed.[^5] The first one is marked **Recommended**.[^6] The other tags mean:

- **Running**: this is the model in use now.
- **On this computer**: the file is already downloaded, so switching needs no download.
- **Recommended**: EZLM's first choice for this computer.
- **Slow**: EZLM estimates fewer than 8 tokens a second, about 6 words a second.[^7]
- **Needs space**: there is not enough free disk for the download right now.[^8]

Each card also shows a plain description of how the model would run, for example "Dense, all 27B used per word; all on the graphics card", or "Mixture of experts, 180B total, 15B used per word; experts in system memory (44 of 60 layers), the rest on the graphics card".[^9] Below that are the file line, a **Smarts** bar, a **Speed** bar and memory bars for the graphics card and system memory.[^10] Select a card to see its own switch button. On the first-run Choose screen, the selected model also shows its file, download size, save folder, speed, context and tool support beside the list.[^11]

Above the list are **Balanced**, **Smartest** and **Fastest**. They change the order and the recommendation, not the model that is running. Balanced means "Smart, at a comfortable speed", Smartest means "Most capable model that fits, even if slow", and Fastest means "Snappy replies first".[^12] Choosing one rescans the machine and selects the new recommendation.[^13] Press **Scan again** after closing apps or plugging in a different graphics card.

### What the numbers mean

**27B** is the number of parameters in billions. A larger number usually means a more capable model that needs more memory. A mixture-of-experts model has a large total, such as 180B, but uses only a few billion parameters per word, which is why it can be bigger than the graphics card and still be quick.[^14]

**GB** on a download button or in the **Download** fact is the size of the file on disk. EZLM shows megabytes below 1 GB, one decimal below 10 GB, and whole gigabytes above that.[^15] The download can be tens of gigabytes, so a slow connection takes a while.

**Memory** on a card is not the same as the download size. It includes the model file, the context cache and the engine's working memory, so it is usually larger than the file.[^16] The bar shows how much the model needs against the memory in the machine, and how much would be left after it loads.[^17] "Not used" means the model keeps nothing in that pool.

**Context** is how much text the model can keep in mind at once, shown as 64k, 32k, 16k or 8k tokens. EZLM tries 64k first and steps down only when the larger context does not fit.[^18] Coding agents work best with 64k, and Hermes needs it.[^19]

**Smarts** compares the model with the best option on this computer, so the top model's bar is full. **Speed** is an estimate in words per second, not a measurement, and it will vary with the prompt and the machine.[^20]

The file line names the exact file, for example "UD-Q4_K_XL by unsloth", and may add "MTP speed-up" or "draft model speed-up" and "q8_0 cache".[^21] A larger file usually loses less quality, and EZLM picks the best file that fits instead of always taking the largest.[^22]

### Will it fit? Memory guidance

EZLM plans against the memory that is free now, not the memory the machine has in total. It keeps a slice back for Windows or macOS and your other apps: about 10% of free memory, with a minimum of 0.75 GB and a maximum of 2 GB. On Windows it keeps more graphics memory back, and more again on AMD and Intel cards.[^23]

If a model you want shows **Needs space**, free some disk space and scan again. You can also start the download and make room while it runs, but the download stops if the disk fills before you do.[^24]

If no model fits, close some apps and press **Scan again**.[^25] **Model mode** on the System page walks you through closing apps one at a time, and nothing closes without your OK.[^26] EZLM may also show a hint such as "Free about 6 GB to run Model Name at ~20 words/s", which tells you what closing apps would unlock.[^27]

If a file for the model is already on this computer and runs at least 85% as well as the best file, EZLM offers the downloaded file instead of a new download.[^28]

### Switching to another model

1. Open **Models**.
2. Select the model you want.
3. Press **Switch to Model Name (no download)**, **Download and switch (N GB)**, or **Resume download and switch (N GB left)**.[^29]

Your current model keeps answering while the new one downloads.[^30] EZLM stops the old server only when the new file is ready, then starts the new model, loads it and asks it a test question.[^31] If the new model fails to start, EZLM puts the previous model back.[^32] Only one change runs at a time, so the button says **Busy with another change** while another job is working.[^33]

### What happens during a download

Setup runs in stages: get the AI engine, download the model, start the server, load the model, ask it a question. The progress bar is split across those stages, and the model download is the largest part.[^34] The model download shows how much is done, how much is left, the speed in MB/s and an estimate of the time left.[^35]

Models come from Hugging Face, and the engine comes from GitHub, so the computer needs internet access for a first setup or a new model.[^36] If a security app or company proxy intercepts secure connections, the download fails with a message that names huggingface.co and github.com.[^37]

Press **Cancel** to stop the job; what was already downloaded is kept, your current model keeps running, and the next attempt resumes from there.[^38] A download that receives no data for 45 seconds is retried automatically, and a connection that keeps dropping is retried until five attempts in a row make no progress.[^39] When a model is a single file, EZLM checks the finished size and deletes a wrong-sized file, then asks you to try again.[^40]

If the disk fills during the download, EZLM stops and tells you how much space to free. Free that space and press **Set it up again**, and the download resumes where it stopped.[^41] EZLM also keeps the computer awake while a setup is running, so a long download is not interrupted by sleep.[^42]

Models are saved in `~/.ezlm/models` by default. On Windows, EZLM may choose the fixed drive with the most free space and save under `EZLM\models` there. You can change the folder under **Settings**. On Windows, the **Saves to** line on the model card shows the current folder.[^43] If space is short, EZLM removes models you are no longer using before it starts, and tells you what it removed. It never removes the model that is running unless it has to make room for a switch, and in that case it warns you that the old model would need downloading again.[^44]
