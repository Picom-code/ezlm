# Install on Windows

EZLM runs on Windows 10 (version 2004 or later) and Windows 11, on regular PCs and on ARM
laptops. The installer is one file for both kinds of PC, it installs only for your Windows
account, and it does not ask for an administrator password. [1]

## Before you start

1. Check your Windows version: **Start > Settings > System > About**, under **Windows
   specifications**. EZLM needs Windows 10 version 2004 or later. [1]
2. On Windows 11, check Smart App Control: **Start > Settings > Privacy & security > Windows
   security > App & browser control > Smart App Control**. If it says **On**, read "If Smart App
   Control blocks it" below before you download. [2]
3. You do not need to install anything else first. EZLM brings its own engine and, if your PC
   lacks it, installs Microsoft's C++ runtime during setup. [3]

## Download and run the installer

1. Download **EZLM-Setup-<version>.exe** (for example EZLM-Setup-0.1.11.exe) from the beta
   download page, `https://github.com/picom-code/ezlm/releases`. [4]
2. Double-click the file. Windows may warn you first. The next two sections say what to click.
3. Setup installs to `%LOCALAPPDATA%\Programs\EZLM`, inside your own profile. There is no folder
   choice and no admin prompt. [1]
4. Tick **Put an EZLM icon on the desktop** if you want a shortcut there. The Start menu shortcut
   is always added. [1]
5. Press **Install**, then **Finish**. Leave **Open EZLM** ticked and EZLM opens. [1]

Running a newer installer over an older EZLM updates it in place. Your models, settings and keys
are kept because they live outside the program folder, and the installer only clears leftover
files from older builds. [5]

If EZLM is running when you start the installer, setup asks Windows to close it and reopens it
when setup finishes. [1]

## If Windows says "Windows protected your PC"

That is SmartScreen, and it appears because this beta is not code-signed yet. [2]

1. Click **More info** under the message.
2. Click **Run anyway**.

If the dialog offers no **More info** link, the file may have been blocked when it was saved.
Right-click the file, choose **Properties**, on the **General** tab tick **Unblock**, then
**OK**, and run it again.

Do not turn SmartScreen off for the whole PC. Running one file is enough.

## If Smart App Control blocks it

On Windows 11 with Smart App Control turned **On**, Windows blocks apps it does not trust, and
there is usually no **Run anyway** button. [2]

1. Open **Windows security > App & browser control > Smart App Control**.
2. If it says **On**, open **Smart App Control settings**, set it to **Off**, then run the
   installer again.
3. Turning it off is one way. Windows will not turn it back on without reinstalling Windows. If
   you want to keep it on, install EZLM on another PC.

If Smart App Control says **Evaluation**, Windows is still deciding and may allow EZLM. Try the
install and see.

## What setup does, and the one permission prompt

- It installs only for your account and adds EZLM to the Start menu. [1]
- It starts EZLM when it finishes. [1]
- On the first model setup, EZLM may install Microsoft's Visual C++ runtime, which the AI engine
  needs. Windows then shows a User Account Control prompt asking whether to allow a program to
  make changes. Click **Yes**. The file is Microsoft's redistributable, downloaded from
  Microsoft. [3]
- If you click **No** on that prompt, the engine cannot start and the first run stops at the
  engine step. Run setup again and allow it.

## If your antivirus flags EZLM

Beta builds are unsigned, so security apps may treat them as unknown. The installer, or the model
server program that EZLM downloads, can be quarantined.

What you may see:

- "EZLM's engine didn't start within 30 seconds. Your antivirus may be scanning it; try again in
  a moment." [6]
- "EZLM's engine stopped while starting. Your antivirus may have blocked it." [6]
- "The model server program was missing, so EZLM is downloading it again", followed by "EZLM's
  model server program is missing and couldn't be restored (...). If an antivirus app removed it,
  allow the folder C:\Users\<you>\.ezlm\bin in that app, then press Start server". [7]
- A download error saying a security app or company proxy is intercepting secure connections. [8]

What to do:

1. Open **Windows Security > Virus & threat protection > Protection history**. Find the EZLM
   item, open it, and choose **Allow on device** (or **Restore**).
2. Add two exclusions: `%LOCALAPPDATA%\Programs\EZLM` and `%USERPROFILE%\.ezlm\bin`. Both are
   under **Virus & threat protection > Manage settings > Exclusions > Add or remove exclusions >
   Add an exclusion > Folder**.
3. In EZLM, open **Overview** and press **Start server**, or close EZLM and open it again. [9]
4. If it happens again, press **Report a problem** and say which security app you use.

Other security suites keep their own quarantine list. Look for the same two folders there. On a
work PC behind a company proxy, ask IT to allow `github.com` and `huggingface.co`. [8]

## Check that it worked

1. The EZLM window opens. On a new install, **Overview** says "Nothing is set up yet". [10]
2. The Start menu has **EZLM**, and **Settings > Apps > Installed apps** lists EZLM. [1]
3. The folder `%LOCALAPPDATA%\Programs\EZLM` contains `EZLM.exe` and an `Engine` folder with
   `ezlm.exe` inside. [1]
4. The **System** page shows your Windows version, your graphics card and the engine EZLM picked
   for it. [11]
5. **Settings > Updates** shows a line such as "EZLM 0.1.11-beta is the latest version." That
   confirms the app is running and talking to its engine. [12]
6. If you want to confirm the engine started, open `%LOCALAPPDATA%\EZLM\engine.log`. The newest
   entry starts with a date and "engine started (pid ...)". [6]

Next, set up a model. The first run is described in "First run" (a03).

## If it still will not start

- Logs are in `%LOCALAPPDATA%\EZLM`: `app.log` and `engine.log`. [13]
- In EZLM, open **Logs** and press **Copy details for support**. Your keys are hidden in the
  copied text. [13]
- Press **Report a problem** and describe what happened.
