# Chat

**Chat** in the list on the left is EZLM's own chat window. It talks to the model running on this computer, with the address and key already filled in, so there is nothing to set up. Nothing you type leaves the machine.

Chat needs your model running. If it is stopped you see **Your model is stopped.** with a **Start server** button; if no model is set up yet you see **Set up a model first: pick one in Models.** (macOS `ChatView.swift:186-199`, Windows `Chat.cs:537-541`). Start the server, then type in the box at the bottom.

## The line at the top

- The dot and word show what your model is doing: **live**, **loading**, **stopped**, **not set up**, **writing**, or **busy with another app** when OpenCode, Hermes or a script is using it (macOS `ChatView.swift:62-71`, Windows `Chat.cs:504-541`).
- **chat size** is how much of the model's memory this conversation has used, as a bar and as a number like `2.1k / 32k` (macOS `ChatView.swift:77-82`).
- **tokens/s** is the answer speed.
- **thinking on / thinking off** lets a thinking model work through the question before it answers. Off sends you straight to the answer (macOS `ChatModel.swift:389`, Windows `Chat.cs:123`).
- **✦ memory** opens what the chat remembers about you (see below).
- **Model** switches to another model you have installed. The chat carries on, and each answer is labelled with the model that wrote it (macOS `ChatView.swift:91-102`, `ChatModel.swift:28`). The switch restarts the server, so wait for it to say **live** again.
- **History** reopens an earlier chat, copies the current one, deletes one or all of them, or opens llama.cpp's own chat page in your browser (macOS `ChatView.swift:103-115`, Windows `Chat.cs:1153-1188`).
- **New chat** starts an empty conversation. It also works with `Command+N` on a Mac and `Ctrl+N` on Windows.

## Asking something

Type in the box and press Return (Enter on Windows) to send. Option+Return adds a new line on a Mac. While an answer is arriving, **Stop** or the Esc key ends it and keeps what was written so far (macOS `ChatView.swift:217-247`, Windows `Chat.cs:291-316`).

The up arrow brings back your last message, with any files, so you can change it and send again. Type `/` to see the commands, and Tab completes one:

- `/remember` and a fact saves something about you for later chats.
- `/forget` and a word removes what it remembers that mentions it.
- `/memory` opens the memory list.
- `/new` starts a new chat.
- `/help` lists them.

Commands are handled by EZLM and never sent to the model (macOS `ChatModel.swift:393-421`, Windows `Chat.cs:750-777`). If you type a slash and no command matches, the message goes to the model as ordinary text.

On an empty chat EZLM offers three example questions. Click one to try it (macOS `ChatModel.swift:83-87`, `ChatView.swift:131-140`).

## Reading the answer

Answers stream in a few words at a time and are drawn as formatted text: headings, lists, quotes, tables, links, and code blocks with their own **Copy** button (Windows `Markdown.cs:12-99`). Under each finished answer you get:

- **Copy** puts the answer on the clipboard.
- **Listen** reads it aloud with the computer's own voice. Press it again to stop (macOS `ChatModel.swift:599-617`, Windows `Chat.cs:951-985`). If Windows has no voice installed, EZLM says so and tells you where to add one.
- **Retry** asks the same question again and replaces the old answer.
- **Continue** appears when the answer hit the model's limit or you stopped it. It sends the end of the answer back and asks the model to go on (macOS `ChatView.swift:301-304`, `ChatModel.swift:575-578`).
- A line with the speed, the number of tokens, and whether messages were left out.

With **thinking on**, the answer first shows its thinking live, then folds it into a **thought for 12s** line you can open. A very long think offers **Answer without thinking** after 40 seconds (macOS `ChatView.swift:329-347`).

## Files

Press **+ file** or drag a text file onto the page. The file is sent with your next question and shown as a tag with its size in tokens (macOS `ChatView.swift:36-44`, `ChatModel.swift:469-497`).

- Text files only: plain text, code, CSV, Markdown, and similar. PDF and Word files are not read yet, and EZLM says to copy their text in instead.
- A file over 2 MB is refused with a note to copy in the part you need.
- A file too large for the model's memory is refused before it is attached, with the token count it would need.
- Older turns make way for a file, but the file and the question have to fit on their own.

## What it remembers

The chat keeps a short list of facts about you, in `memory.md` next to its saved chats, and sends them to the model at the start of each new chat as background, not as instructions (macOS `ChatData.swift:114-241`, Windows `Memory.cs`).

- After a chat goes quiet for about 8 seconds, the model is asked once for lasting facts you mentioned. New ones appear under the answer as **✦ remembered** with a **forget** button (macOS `ChatModel.swift:425-457`, Windows `Chat.cs:784-820`).
- **✦ memory** shows every fact, lets you delete one, add one, write your own instructions ("keep answers short"), and turn the whole thing off.
- Facts are kept under 1,500 characters, about 400 tokens. When it is full EZLM says **Memory is full: remove something in Memory first.**
- Things that look like an instruction or a secret are not saved, for example "ignore previous instructions", a password, or a card number (macOS `ChatData.swift:186-210`).

## Saved chats

Every chat is saved on this computer as you go, one file per conversation, so closing EZLM does not lose it. On Windows they are in `%LOCALAPPDATA%\EZLM\chats`; on a Mac in `~/Library/Application Support/EZLM/chats` (macOS `ChatData.swift:3-15,49`, Windows `ChatStore.cs:43`). The first time you open Chat, the most recent chat from the past week comes back (macOS `ChatModel.swift:125-131`, Windows `Chat.cs:93-97`). **History** lists the last 15, and **Copy this chat** copies the whole conversation as text.

## Limits to know about

- One conversation at a time. There are no folders, no search, and no editing an earlier question. **Retry** only redoes the last one.
- The model reads a fixed amount of text at once. When a chat gets near that, EZLM leaves out the oldest messages and shows **This chat has nearly filled the model's memory, so its oldest messages are left out from here. New chat starts fresh.** (macOS `ChatView.swift:200-202`, Windows `Chat.cs:538`). Answers then start to forget the beginning of the conversation.
- An answer can stop at the model's own limit. Use **Continue** to carry on, or ask for something shorter.
- Text only. There is no picture, audio or PDF input, and no web browsing: the model answers from what it was trained on and what you paste in.
- If the whole question and file still do not fit, EZLM says **That's more than the model can read at once, even with older messages left out. Try a shorter message or file.**
- Quitting EZLM in the middle of an answer stops it there. What was written so far is kept (macOS `AppModel.swift:195`, Windows `Chat.cs:533`).
- Chat is one app using the model. Another app using it at the same time shares the same server, so answers can be slower, and the top line says **busy with another app**.
- The key is filled in for you here. Other apps still need the URL and key from **Connect** or **Keys**.

## If an answer fails

Each of these appears in place of the answer, and asking again usually clears it:

- **Your model is still loading. Try again in a moment.** The server is starting.
- **Couldn't reach your model. It may have stopped: check Overview.** Start the server again.
- **Your model stopped in the middle of answering. Check Overview, then ask again.**
- **It didn't answer. Try asking again.** and **It thought about it but didn't write an answer. Try asking again.** The model returned nothing.
- **The server didn't accept EZLM's key. Restart EZLM; if it keeps happening, report a problem.**
- **Something went wrong:** followed by the system's own words.
