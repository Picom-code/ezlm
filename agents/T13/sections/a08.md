# Updating and uninstalling EZLM

## Updating

EZLM checks for a new version when it opens and keeps the answer for an hour.[^1] To check by hand, open **Settings**, find **Updates**, and press **Check for updates**.[^2] When a new version is out, EZLM shows its version number, the download size, and an **Update to x.y.z** button.[^3] On Windows, EZLM tells you your model keeps running while EZLM restarts itself.[^3] On both platforms EZLM opens again by itself when the update is finished.[^4]

What happens when you press the button:

1. EZLM downloads the installer to a temporary folder on your computer.[^5]
2. It checks the file against the fingerprint (SHA-256) that GitHub publishes for it. If they differ, EZLM deletes the file and installs nothing.[^6]
3. On **Windows**, EZLM closes its own helper processes, starts the downloaded installer silently, and quits. The installer replaces the app's files and opens EZLM again.[^7] If the installer stops early, it opens the copy of EZLM that is already installed, so you are not left without the app.[^8]
4. On a **Mac**, EZLM mounts the disk image, checks that it contains EZLM, copies the new version next to the old one, swaps them, and opens the new one.[^9] If it cannot write to Applications, it opens the disk image and asks you to drag EZLM into Applications yourself.[^10]

If you quit during the download, the update stops and you can start it again from Settings.[^11] A second try reuses a complete downloaded file instead of fetching it again.[^12]

If EZLM was opened straight from the disk image or from Downloads, macOS runs it from a temporary read-only copy. EZLM shows a note asking you to drag it into Applications, because it cannot replace itself there.[^13] Move it to Applications first, then update.

If checking fails, Settings says "couldn't reach GitHub to check for updates" or "checking for updates failed (…)".[^14] Your installed version keeps working, so try again later. After an update, Settings shows the new version number, and your models and chats are unchanged.[^15]

## Uninstalling on Windows

You can remove EZLM in either of two ways:

- **Settings > Apps > Installed apps > EZLM > Uninstall.** This removes the app, its shortcuts and its startup entry.[^16]
- **Inside EZLM: System > Remove models and settings.** This stops the model and deletes the models, settings and keys, but leaves the app installed.[^17]

The uninstaller asks "Also delete the AI models EZLM downloaded, and its settings and keys?" and the default answer is **No**.[^18]

- **Yes** stops the model server, removes the startup entry, deletes the models (including models on another drive) and deletes the data folder.[^19]
- **No** stops the model server and keeps the data, and does not record it as your choice, so a reinstall starts the model again.[^20]

What is left behind on Windows:

- If you answered **No**, `%USERPROFILE%\.ezlm` stays. It holds the models, the settings, your API keys, the logs and the downloaded engine.[^21] A later reinstall finds the models and does not download them again.[^22]
- In both cases, `%LOCALAPPDATA%\EZLM` stays. It holds chat history, memory and the app's own logs, and neither uninstall path deletes it.[^23] Delete the folder by hand if you want it gone.
- In both cases, the downloaded installer stays in `%TEMP%\EZLM-update` until Windows clears its temporary files.[^5] It is safe to delete.
- The startup entry is removed either way, so EZLM does not come back at sign-in.[^24]
- If you used the in-app button, EZLM is still open and scans again, which recreates an empty `%USERPROFILE%\.ezlm` folder. An empty folder is expected.[^32]

## Uninstalling on Mac

1. In EZLM, open **System**, press **Remove models and settings**, then **Remove everything**.[^25]
2. Drag **EZLM** from Applications to the Trash.[^26]

The button stops the model, removes the login item, and deletes the models, the settings and the keys.[^27]

What is left behind on a Mac:

- `~/Library/Application Support/EZLM` stays. It holds chat history and memory, because the uninstall deletes only `~/.ezlm` and the model folders.[^28] Delete the folder by hand.
- The login item `~/Library/LaunchAgents/com.ezlm.server.plist` is removed by the button.[^29] If you drag the app to the Trash without pressing the button first, the file stays and points at an app that is no longer there, so delete it by hand.
- The disk image in Downloads, and the temporary copy in `$TMPDIR/EZLM-update`, stay until you or macOS deletes them.[^30]
- If you skip step 1, `~/.ezlm` stays with the models, settings and keys, and a reinstall finds the models again.[^31]
- After the button, EZLM is still open and scans again, which recreates an empty `~/.ezlm` folder. An empty folder is expected, and you can delete it once EZLM is closed.[^32]

## Reinstalling later

On both platforms, a reinstall that keeps the data folder skips the model download and starts the model at sign-in again.[^22] To start from scratch instead, answer **Yes** on Windows, or press **Remove models and settings** on a Mac before trashing the app, and then reinstall.
