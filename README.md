# EZLM

Your own AI model, running on your own computer. EZLM checks your PC, picks the smartest model it can run well, sets it up, and gives you a private URL and API key.

**Download:** https://picom-code.github.io/ezlm/ (Windows 10/11, x64 and ARM; Mac beta for Apple Silicon on the [releases page](https://github.com/picom-code/ezlm/releases/latest)).

This is a beta. See the release notes for how to install it and how to report problems.
